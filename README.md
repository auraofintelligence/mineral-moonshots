Static multi-page website prototype for curious local island minds exploring far-out Mineral Moonshots: underground, mineral-sands-informed, environmentally careful, citizen-caring pathways toward a spacefaring super civilisation.

## Open It

Run a small local server from this folder:

```powershell
python -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Structure

- `index.html` is the compact gateway page.
- `moonshots.html` is the far-out moonshot collection.
- `materials.html` is the mineral-sands and underground systems page.
- `build-path.html` shows local projects as stepping stones, not the hero of this site.
- `worlds.html` holds the citizen-care, culture, longevity and abundance worlds.
- `labs.html` collects the interactive thinking tools.
- `boundaries.html` keeps public, private, fiction and permission lines visible.
- `briefs/` contains the separate concept pages.
- `site-data.js` holds the page content in one simple place.
- `styles.css` holds the Strange but True inspired layout with a new mineral-metal colour scheme.
- `assets/heroes/` contains the WebP title-page hero images.
- `assets/noticeboard-network.webp` is the public media-spine concept showing wall, tablet, phone, kiosk and fallback surfaces.
- The brief pages include interactive labs: a Kardashev dial, layer map, biosphere calculator, kiosk simulator, compute sketch, grant quest, co-op sorter, sports node map, space path, reality sorter and archipelago map.
- The newer pages add island abundance, alien necklace alignment film, protopian music/story culture, cosmic nexus / abyss protocol, and loving longevity commons.
- The build-path page includes local projects and repo links. Public repos link out directly; private and local workbenches are labelled as boundaries.
- `profile.md`, `aura.md`, `dreamtime.md` and `public-honour-board.md` are plain text source notes for the newest public/private/fiction layers.
- The site is intended to connect back to the Strange But True downloads shelf as Sample World 08.
- Treat the site as a public moonshot collection and shared game-world sandbox, not a certainty, approval or ready-to-build claim.
- Do not collapse this site into a single long page. The content needs bite-sized pages.
