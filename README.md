# Mineral Moonshots

Static website prototype for curious local island minds exploring Mineral Moonshots as windows and doors into plausible worlds we can start building from now.

## Open It

Run a small local server from this folder:

```powershell
python -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Structure

- `index.html` is the main page.
- `briefs/` contains the separate concept pages.
- `site-data.js` holds the page content in one simple place.
- `styles.css` holds the Strange but True inspired layout with a new mineral-metal colour scheme.
- `assets/mineral-city-map.svg` is the main visual asset.
- `assets/noticeboard-network.webp` is the public media-spine concept showing wall, tablet, phone, kiosk and fallback surfaces.
- The brief pages include interactive labs: a Kardashev dial, layer map, biosphere calculator, kiosk simulator, compute sketch, grant quest, co-op sorter, sports node map, space path, reality sorter and archipelago map.
- The newer moonshot pages add island abundance, alien necklace alignment film, protopian music/story culture, cosmic nexus / abyss protocol, and loving longevity commons.
- The homepage includes a recent repo moonshots section. Public repos link out directly; private and local workbenches are labelled as boundaries.
- `profile.md`, `aura.md`, `dreamtime.md` and `public-honour-board.md` are plain text source notes for the newest public/private/fiction layers.
- The site is intended to connect back to the Strange But True downloads shelf as Sample World 08.
- Treat the site as a public moonshot collection and shared game-world sandbox, not a certainty, approval or ready-to-build claim.
