# Public Honour Board

This is a narrative planning brief for a public-safe honour board inside the Mineral Moonshots game-world.

It is not a live ledger, a public database, a fundraising claim or a promise that any person, club, organisation or project has opted in.

## Purpose

The honour board is a ceremonial display layer for visible local support. It could appear on wall screens, kiosk panels, web pages or community displays.

The useful version shows appreciation without leaking private life.

## What can be public

- Display name or chosen name.
- Public profile.md link or summary.
- Approved project name.
- Broad support type.
- Public wallet transaction reference, if the supporter has chosen to move that support onto a public ledger.
- XRP transaction hash, Solana transaction hash or another supported public ledger reference.
- Public-safe contribution summary.
- Approved image or symbol.
- Thank-you note.

## Public ledger layer

Some supporters may eventually want their visible support to connect with public wallet transactions.

The first ledger examples are XRP and Solana. Other ledgers can be added later if they make sense.

The honour board should show only the public-safe reference: profile.md, chosen display name, project name, public transaction hash and contribution summary.

The board should not pretend a wallet proves identity by itself. Identity, project connection and public display all still need consent and approval.

## What stays private

- Phone numbers, emails and addresses.
- Private payments and financial details that were not deliberately made public.
- Exact GPS points or sensitive locations.
- Emergency contacts.
- Unapproved photos or media.
- Private wallet notes, seed phrases, account access, balances or unrelated transaction history.
- Cultural claims that have not been invited or checked.

## Game-world experiment

Start with fictional sample entries before using real names. Let locals decide whether it feels like appreciation, pressure, accountability, theatre or something else.
